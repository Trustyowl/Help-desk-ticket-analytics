\# Help Desk Ticket Analytics



A portfolio project using SQL and Python to analyze simulated IT help desk ticket data.



\## Project Overview



This project simulates a basic IT help desk analytics workflow. Ticket data is stored in CSV format, imported into a SQLite database, analyzed using SQL, and further explored using Python and pandas.



The project focuses on identifying ticket trends, common technical problems, resolution times, SLA performance, technician performance, and customer satisfaction.
